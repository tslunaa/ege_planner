# Планер ЕГЭ-2027 по информатике — запуск

Приложение состоит из обычных файлов: `index.html`, `app.js`, `styles.css`, `config.js`.
Пока `config.js` не заполнен, работает **локальный режим**: данные хранятся только в этом браузере, и ссылки для учениц на других устройствах не откроются.
Чтобы ученицы могли в любой момент открыть свою карточку с телефона, сделайте три шага ниже (один раз, около 15 минут).

## Шаг 1. Облачная база (Supabase, бесплатно)

1. Зайдите на https://supabase.com и зарегистрируйтесь.
2. **New project** → придумайте название (например, `ege-planner`) и пароль базы (сохраните его) → регион поближе (например, Frankfurt) → **Create**.
3. Когда проект создастся: слева **SQL Editor** → **New query** → вставьте всё содержимое файла `supabase-setup.sql` → **Run**. Должно появиться «Success».

## Шаг 2. Подключить приложение к базе

1. В Supabase: **Project Settings → API** (или кнопка **Connect**).
2. Скопируйте **Project URL** и ключ **anon / public**.
3. Откройте `config.js` и вставьте их в кавычки:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJ...",
   ```
   Ключ `anon` публичный по назначению: данные защищены правилами доступа в базе. **Никогда** не вставляйте сюда ключ `service_role`.

## Шаг 3. Сайт на GitHub Pages

Код лежит в репозитории https://github.com/tslunaa/ege_planner.
1. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
2. Через 1–2 минуты сайт откроется по адресу **https://tslunaa.github.io/ege_planner/**.
3. После изменения `config.js` (шаг 2) отправьте изменения в репозиторий: сайт обновится сам.

## Первый вход

1. Откройте адрес сайта → **Создать аккаунт** (почта и пароль) → подтвердите почту по письму → **Войти**.
2. Рекомендуется: после создания своего аккаунта в Supabase откройте **Authentication → Sign In / Providers** и выключите **Allow new users to sign up**. Посторонние всё равно не увидели бы ваших учениц, но так чище.
3. Укажите адрес сайта `https://tslunaa.github.io/ege_planner/` в **Authentication → URL Configuration → Site URL**.

## Ссылка для ученицы

Карточка ученицы → **Настройка** → **Ссылка для ученицы** → **Скопировать** и отправить ей.
Ученица открывает ссылку без регистрации и видит главный экран, маршрут, карту знаний, занятия, ошибки и пробники, но ничего не может изменить.
Заметки из блока «Только для репетитора» ей не показываются.
Если ссылка ушла не туда, нажмите **Сменить ссылку**: старая перестанет работать.

## Перенос данных из локального режима

Если вы уже что-то заполнили в локальном режиме: карточка → **Настройка** → **Скачать резервную копию**.
После подключения облака: главная → **Импорт копии**.

## Важно знать

- На бесплатном тарифе Supabase ставит проект на паузу, если в нём **7 дней не было активности**. Тогда в панели Supabase нужно нажать **Restore project**, данные при этом не теряются. При регулярной работе пауза не наступает.
- Раз в месяц полезно скачивать резервные копии карточек.
- Структура заданий взята по **проекту** КИМ ЕГЭ-2027: на 14.10.2026 ФИПИ публиковал документы как проекты. Изменения: №10 — маска подсети, №13 — анализ хода исполнения алгоритма, №23 — графы (кратчайшие пути, количество путей в ациклическом графе), №27 — ответ одной строкой из двух чисел. Всего 27 заданий, максимум 29 первичных баллов, 3 ч 55 мин. Когда выйдут окончательные материалы, сверьте темы в «Карте знаний»: все поля редактируются.

## Посмотреть локально, без публикации

Откройте Терминал в этой папке и выполните `python3 -m http.server 8765`, затем откройте в браузере http://localhost:8765.
